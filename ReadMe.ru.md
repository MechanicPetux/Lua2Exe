# Lua2Exe
Простая программа, компилирующая скрипты Lua в исполняемые файлы.

## Установка
* Вам нужен Си компилятор в %PATH%
* Windows: Скачайте релиз, распакуйте где нибудь в %PATH%, и отредактируйте Config.lua под вашу среду.
* Другие системы: вам будет нужно скомпилировать L2E самостоятельно, имеется скрипт Make.ps1, и если у вас есть powershell, gcc и Lua, просто запустите его.
Или отредактируйте, чтобы подходил под компилятор и оболочку. После компиляции, отредактируйте Config.lua под вашу среду.
И наконец, либо переместите конфиг туда, где Луа сможет его взять, либо передавайте "-conf путь" для каждой компиляции.

По вопросам установки и использования, я написал короткий [мануал](https://mechanicpetux.lol/lua2exe/manual.html) описывающий всё в деталях. (пока только на Английском😢)

## Использование
`l2e [опции] [модули...] основной_файл`

Доступные опции:
<table>
	<tr><td>-o Файл</td><td>Задаёт имя получившегося файла</td></tr>
	<tr><td>-c Компилятор</td><td>Задаёт компилятор Си. Поддерживаемые компиляторы: "gcc", "clang", "tcc"</td></tr>
	<tr><td>-conf Путь</td><td>Задаёт путь конфига компилятора; файл должен быть доступен для require()</td></tr>
	<tr><td>-s</td><td>Убрать дебаг информацию из exe</td></tr>
	<tr><td>-dll</td><td>Линковать exe динамически</td></tr>
	<tr><td>-M</td><td>Только объединить файлы в один, не компилировать</td></tr>
	<tr><td>-C</td><td>Только компилировать файлы в Си, не компилировать в exe</td></tr>
	<tr><td>-v</td><td>Многословить (это только выводит комманду для компилятора Си)</td></tr>
	<tr><td>-np</td><td>Убрать код парсинга, уменьшает размер exe</td></tr>
	<tr><td>-a Опции</td><td>Дополнительные опции, которые нужно послать компилятору Си</td></tr>
	<tr><td>-[h | ?]</td><td>Показать эту инфу</td></tr>
</table>

> [!IMPORTANT]
> * Порядок Луа файлов важен. Главный файл должен быть последним.
> * Имена модулей должны быть такими же, как и в `require`. То есть *My.lua* это *My*.
> * Так как нет надёжного способа определить все зависимости, для того, чтобы сделать независимый exe, все модули должны быть предоставлены во время компиляции.

## Функции
Основные функции:
* Компиляция в независимый exe
* Компиляция в динамически линкуемый exe
* Поддержка и Луа, и Си зависимостей
* Поддержка разных компиляторов (Типа. Я не тестировал это, и скорее всего это будет заменено в следующем обновлении)

> [!NOTE]
> Я не уверен насчет портируемости. По большей части из-за временных файлов.
